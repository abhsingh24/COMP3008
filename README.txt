Instructions to run implementation:
Download and extract zip file
Enter COMP3008 folder
Open index.html in a web browser (double-click it on Windows or Mac)
or
Enter COMP3008 folder in terminal
Type in "start index.html" (Windows) or "open index.html" (Mac)

Software / dependencies:
- A modern web browser (Chrome, Firefox, Edge or Safari). No installation or server is needed.
- An internet connection, because jQuery and Font Awesome are loaded from a CDN.

Grader Instruction to complete task:
Grader should start in the home page and select "Parking Permit" Permit dropdown from the menu,
enter vehicle information following the instructions given. Continue to permit page and select "P7" to complete task, select from drop down when you want to obtain the permit for and continue to the page requiring card information. Lastly input card information submit and go to home page to complete task.

Test cards for the payment page (any future expiry date and any 3-digit CVC):
- 4242 4242 4242 4242: payment is approved
- 4000 0000 0000 0002: payment is declined (error and recovery path)
